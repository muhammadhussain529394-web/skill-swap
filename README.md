# SkillSwap - Peer-to-Peer Skill Exchange Platform

SkillSwap is a web application designed for students to trade skills, offer task assistance, and learn together without monetary costs. It features a responsive frontend and a live Firebase Cloud database backend.

---

## 🚀 Key Features

- **Offer vs Need Badging:** Distinct visual badges for users offering skills vs those requesting help.
- **Real-time Firebase Integration:** Cloud database synchronization using Firebase Firestore SDK for publishing and reading skill posts.
- **Report & Safety System:** Flag improper requests directly to the database.
- **Interactive Filtering & Search:** Filter skill requests by categories (JavaScript, HTML/CSS, UI/UX, Python) or live search.
- **Direct Connect Options:** Quick-action connections with skill partners via WhatsApp or Email.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, CSS3, JavaScript (ES6+ Modules)
- **Framework:** Bootstrap 5.3 (Responsive Layout, Modals, Toasts)
- **Backend & Database:** Firebase Firestore (NoSQL Cloud Database)
- **Version Control & Hosting:** Git, GitHub, Vercel
